## Features

- A hero section ("Transform through outdoor training") with a free consultation
  call to action
- Pages for PT services, 60-minute sessions, group and pairs training, and
  client transformations
- **Pricing**, **programmes**, **workouts**, and **nutrition** pages
- A local **park guide** for outdoor training spots
- An **Active Living** article series
- Expanding-card UI and a responsive navigation bar
- Privacy policy and terms pages

## Tech stack

Hand-written HTML, CSS, and vanilla JavaScript, deployed on Vercel.

```
index.html, about.html, pricing.html, Programs.html, Workouts.html, Nutrition.html
Park-Guide.html, Active-Living-1..3.html, Privacy-Policy.html, Terms-and-conditions.html
Styles/, Script/, pics/
```

## Run locally

```bash
git clone https://github.com/dean1234533/Fitness-Website.git
```
